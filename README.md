# Mzali Bakery 🎂
### AI-Powered Bakery Planning & Booking System

Welcome to the **Mzali Bakery** repository. Mzali Bakery is an artisanal, mobile-first web application designed to help customers find, plan, customize, and book cakes seamlessly using an intelligent AI Cake Concierge.

---

## 🌟 Key Features

- **🍰 Interactive Cake Catalogue:** Browse by occasion (Birthday, Wedding, Graduation, Baby Shower, Anniversary) or flavour with transparent pricing in South African Rand (ZAR / `R`).
- **🎨 6-Step Cake Planner:** Step-by-step customizer choosing occasion, sponge & filling flavour, portion sizing, custom decorations, and piped messages.
- **💰 Real-Time Dynamic Price Calculator:** Transparent live cost breakdowns covering base cake, size markups, decor add-ons, and delivery.
- **🤖 AI Cake Concierge:** Grounded AI chatbot offering accurate portion guidance based on guest count, flavour pairings, and live inventory availability.
- **📅 Delivery & Fulfilment Scheduling:** Calendar validation enforcing minimum prep lead times (48 hours for standard cakes, 7 days for wedding/multi-tier cakes).
- **📋 Customer Portal ("My Bookings"):** Digital receipt cards and live order tracking (`Pending`, `Confirmed`, `Ready`, `Completed`, `Cancelled`).
- **👨‍🍳 Bakery Admin Control Center:** Order management pipeline, live catalogue CRUD, inventory toggles, and status progression.

---

## 🏗️ System Architecture

- **Frontend:** Mobile-first TanStack Start / React, Tailwind CSS, shadcn/ui components.
- **Backend Services:** Lovable Cloud with PostgreSQL database, Row-Level Security (RLS), and Lovable AI integration.
- **Currency:** South African Rand (ZAR / `R`).
